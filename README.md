# Wireframe de Média Fidelidade - One Page

## 📖 Sobre o projeto

Este projeto foi desenvolvido como parte do desafio da DIO (Digital Innovation One).

O objetivo foi criar um wireframe de média fidelidade para uma página única (One Page), demonstrando a organização dos componentes e a estrutura da interface.

---

## 🎯 Objetivo

Criar um wireframe de média fidelidade contendo:

- Logo
- Hero Banner
- Imagem do Produto
- Botão Primário
- Botão Secundário
- Seção de Depoimentos
- Rodapé
